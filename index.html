Change Wi-Fi network
The SlopeSense unit always keeps its own network SlopeSense. Here you choose the one network it joins (your phone hotspot). There is no fallback: if that network is off, open the dashboard through SlopeSense at 192.168.4.1. Saved on the board, no reflashing.
Tip: tap a network from the scan so the name is exact. If it can't join, it keeps trying; the SlopeSense network always stays on.
Cloud dashboard (view from anywhere)
Sends this dashboard's data through a free HiveMQ Cloud broker, so the cloud page works from any phone or laptop on any internet. Needs internet on the Wi-Fi above (phone hotspot with mobile data). Saved on the board.

Controls
